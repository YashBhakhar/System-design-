# Security policy

Concept Map is a static website: there is no backend, no login and no user data on a server. Progress is stored only in each visitor's own browser. Security problems are still possible, for example a script injected through concept content, or a vulnerable dependency.

## Reporting a problem

**Please don't open a public issue for security problems.** Instead, report it privately:

- on GitHub: the repository's **Security** tab → **Report a vulnerability**, or
- by email: ybhakhar10@gmail.com

Please include what you found, how to reproduce it, and which page or file is affected. You'll get a reply within 7 days, and we'll let you know when it's fixed.

## Supported versions

Only the latest version on the `main` branch is supported.
